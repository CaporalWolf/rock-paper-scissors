Musiques ambiantes (MP3)

1. Placez vos fichiers .mp3 dans ce dossier.

2. Pistes actuelles (tracks.json) :
   music 1.mp3 … music 8.mp3

   Avec « npm start », toute autre piste .mp3 ajoutée ici
   est aussi détectée automatiquement.

Les ambiances se lancent à des moments aléatoires (menu ou partie).
Réglez le volume avec « Volume musique » dans les paramètres.
